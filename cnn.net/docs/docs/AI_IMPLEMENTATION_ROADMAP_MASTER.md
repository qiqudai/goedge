## 2. 分阶段开发门禁
### Phase 0 基座
- 动态配置快照
- YARP 动态路由
- 配置幂等与回滚

### Phase 1 安全与证书
- TLS/SNI 热更新
- ACL/WAF/CC 执行链
- 权限分级框架

### Phase 2 可观测与治理
- 统一日志读写
- 调试开关与人工调试日志
- 审计链闭环

### Phase 3 扩展与高阶能力
- 插件 DLL 运行时
- L4 Stream 代理
- 性能压测与容量治理

## 3. 强制门禁（每阶段必须满足）
- 功能门禁：对应 AI_SPEC DoD 全满足。
- 稳定门禁：无关键 panic/崩溃，失败可降级。
- 性能门禁：达到文档 SLO。
- 运维门禁：有指标、有日志、有回滚。

## 4. 测试策略统一要求
- 单元测试覆盖核心算法与边界。
- 集成测试覆盖 WS 下发到生效完整链路。
- 压测覆盖高并发、日志洪峰、规则复杂度上限。
- 混沌测试覆盖：配置错误、插件崩溃、磁盘满、上游大面积故障。

## 5. 硬件容量基线（建议）
### 5.1 边缘节点（中规模）
- CPU：16C
- 内存：32GB
- 磁盘：NVMe 1TB（缓存+日志建议分盘）
- 网络：10GbE

### 5.2 控制面节点
- CPU：8C
- 内存：16GB
- 数据库 SSD：500GB+

## 6. 峰值瓶颈优先级
1. 规则链 CPU 与正则复杂度
2. 缓存与日志磁盘 IO
3. WS 与任务队列拥塞
4. 上游慢响应导致连接堆积

## 7. 标准缓解手段
- 规则预编译与预算控制
- 批量日志与回压
- 连接池与超时分层
- 熔断、重试、摘除
- 节点级灰度和快速回滚

## 8. 里程碑输出物（每阶段）
- 代码 PR
- 变更说明
- 运行手册
- 监控面板
- 回滚预案

## 9. 最终完成判定
- 文档中的模块均有实现与测试映射。
- 在目标硬件下通过峰值压测。
- 线上灰度运行稳定达到 SLA 周期（建议 14 天）。
