# 功能点限制/技巧/关键实现点矩阵

## 1. YARP 动态路由
- 限制：单节点建议域名 <= 2 万；配置 JSON <= 20MB。
- 技巧：路由与集群预编译成快照，原子替换。
- 关键点：失败保持 last-good；fallback 模式可观测。

## 2. TLS/SNI
- 限制：证书对象不可在请求路径频繁加载。
- 技巧：按域名缓存 `X509Certificate2`，增量替换。
- 关键点：SNI miss 回退 fallback 证书并告警。

## 3. ACL/WAF/CC
- 限制：单请求规则链预算 P95 < 2ms。
- 技巧：CIDR Trie + 规则预编译 + 正则超时。
- 关键点：执行顺序固定，白名单短路优先。

## 4. 插件 DLL
- 限制：必须签名校验；不可直接访问宿主敏感资源。
- 技巧：隔离加载上下文 + 熔断 + 快速卸载回滚。
- 关键点：插件异常不拖垮主链路。

## 5. 控制面同步
- 限制：版本必须单调；任务处理幂等。
- 技巧：`version + force` 组合语义，ACK 明确。
- 关键点：`ok/skipped/fail` 机器可判定。

## 6. 日志与调试
- 限制：日志写入不能阻塞主请求。
- 技巧：Channel 批量写 + 回压策略 + 开关热更新。
- 关键点：人工调试日志结构化且可审计。

## 7. L4 Stream
- 限制：端口冲突与 FD 上限必须受控。
- 技巧：`SocketAsyncEventArgs` 池化与连接治理。
- 关键点：慢连接淘汰、空闲超时、熔断摘除。

## 8. 性能与容量
- 限制：磁盘高水位 >85% 需降级。
- 技巧：缓存/日志分盘、批量落盘、限流保护。
- 关键点：容量模型必须覆盖 CPU/内存/IO/网络。

## 9. 权限分级
- 限制：默认拒绝，禁止路径硬编码临时放行。
- 技巧：permission catalog 内存快照。
- 关键点：L1认证/L2授权/L3资源归属三层防线。
